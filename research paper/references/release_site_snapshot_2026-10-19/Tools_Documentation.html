Tools & Documentation

On this page we gather all the tools and code that we wrote / adapted during the course of our work on this paper. We also include on this page high-level documentation for the datasets that generalises across different attack classes.

Paper Code repository

All code that we used for our paper can be found in this repository. This includes labelling code for the datasets as well as code used for our experiments.

Improved CICFlowMeter Tool

Our fixed version of the CICFlowMeter tool can be found at https://github.com/GintsEngelen/CICFlowMeter.

Changes made in previous work

  • A TCP flow is no longer terminated after a single FIN packet. It now terminates after mutual exchange of FIN packets, which is more in line with the TCP specification.
  • An RST packet is no longer ignored. Instead, the RST packet also terminates a TCP flow
  • CICFlowMeter fixed as per this GitHub pull request (Fwd and Bwd Bulk features affected)

Changes made during this work

  • Changed the timestamp to output in UTC and with microsecond precision
  • Added ICMP protocol support as well as a bunch of ICMP-related features
  • Added Total TCP Duration feature
  • Added Forward RST and Backward RST features
  • Fixed TCP Segmentation Offset issue (more details in our paper under section IV-B.
